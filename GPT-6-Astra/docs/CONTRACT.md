# Internal implementation contract

Pure Dart production core in `app/lib/core/core.dart`, imported by Android and CLI. Core uses Map<String,dynamic> typedef Json. Dates use YYYY-MM-DD, timestamps ISO8601 with local-calendar prefix retained. All UI mutable actions await Store.put(collection, item), Store.remove(collection,id), Store.updateSettings(map), Store.replace(document). Store owns persisted Json document. AppModel wraps store and notifyListeners after action.

Document: {format:"morphhealth",version:1,settings:{language:"de",weightUnit:"kg",onlineFood:false,cyclePredictions:true,visible:{nutrition:true,cycle:true,weight:true,symptoms:true},goals:{water:nullable number,energy:nullable number,protein:nullable number,carbs:nullable number,fat:nullable number}},foods:[],meals:[],drinks:[],periods:[],weights:[],symptoms:[]}

Every collection item has string id. foods: {id,name,source:"custom"|"off",barcode?:string,brand?:string,basis:"g"|"ml",servingSize:number?,nutrients:{energy:number?,protein:number?,carbs:number?,fat:number?,saturatedFat:number?,sugar:number?,fiber:number?,salt:number?,sodium:number?,caffeine:number?,vitaminA:number?,vitaminC:number?,vitaminD:number?,vitaminE:number?,vitaminK:number?,vitaminB1:number?,vitaminB2:number?,vitaminB3:number?,vitaminB5:number?,vitaminB6:number?,vitaminB7:number?,vitaminB9:number?,vitaminB12:number?,calcium:number?,iron:number?,magnesium:number?,potassium:number?,zinc:number?,selenium:number?,iodine:number?,phosphorus:number?},favorite:bool}. nutrient units: energy kcal, macros/salt/fiber/sodium g, caffeine mg; micronutrients mg except A,D,K,B7,B9,B12,selenium,iodine µg. All per 100 g/ml. Null/missing = unknown, zero is known. No g/ml conversion without explicit density; selecting unit not same as basis prohibited except serving.

meals: {id,food: food snapshot,amount:number,unit:"g"|"ml"|"serving",at:ISO8601,meal:"breakfast"|"lunch"|"dinner"|"snack",note:string}. Food snapshot preserves original nutrients on custom food edit. drinks:{id,kind:"water"|"caffeine",amount:number,at:ISO8601,note:string}. amount ml or mg. periods:{id,start:date,end:date|null,flow:"spotting"|"light"|"medium"|"heavy",note:string}; one record describes one period episode. weights:{id,at:ISO8601,kg:number,note:string}; symptoms:{id,at:ISO8601,name:string,intensity:integer 0..10,note:string}.

- Json cycleForecast(Json doc,String on): {status:"disabled"|"insufficient"|"ready",on,intervals:[num],sampleSize:int,cycleLength:num|null,predictedStart:date|null,earliest:date|null,latest:date|null,explanation:{de:string,en:string},...}; retrospective on uses only periods starting <=on, excludes spotting, robust recent history.
- List<Json> history(Json doc,{String? from,String? to,String? area,String query='',int offset=0,int limit=100}): list {collection:string,item:Json,date:string,title:string}; area nutrition (meals/drinks),cycle,weight,symptoms. descending date.
- class Store {Store(Directory dir,List<int> key); Json document; Future<void> open(); Future<void> put(String collection,Json item); Future<void> remove(String collection,String id); Future<void> updateSettings(Json settings); Future<void> replace(Json doc); Future<void> clear(); Future<void> close();} serial atomic encrypted authenticated save, import validation strict.
